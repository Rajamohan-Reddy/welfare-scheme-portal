# Welfare Scheme / Service Management Portal

## Project Overview

The Welfare Scheme / Service Management Portal is a full-stack MERN application designed to digitize government welfare scheme application and approval processes.

The system allows citizens to register, browse available schemes, submit applications, upload required documents, and track application status online.

Government officers can verify submitted applications, request corrections, approve or reject requests, and maintain application processing records.

Administrators can manage schemes, officers, dashboard reports, and monitor overall system activities.
